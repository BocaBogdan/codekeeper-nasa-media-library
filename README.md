# NASA Media Library

A React app to search the [NASA Image and Video Library](https://images.nasa.gov)
and view the details of an image, using the public NASA Images API
(`https://images-api.nasa.gov`).

> Work in progress: the project setup is in place; the Search and Details pages
> are placeholders for now.

## Tech stack

- [Vite](https://vite.dev) + [React](https://react.dev) + TypeScript (strict mode)
- [TanStack Router](https://tanstack.com/router) with file-based routing
- [TanStack Query](https://tanstack.com/query) for data fetching and caching
- [Tailwind CSS](https://tailwindcss.com) v4 + [shadcn/ui](https://ui.shadcn.com) (light theme)
- [react-hook-form](https://react-hook-form.com) + [zod](https://zod.dev) for forms
- [Vitest](https://vitest.dev) + [React Testing Library](https://testing-library.com/docs/react-testing-library/intro) + jsdom
- ESLint (typescript-eslint, react-hooks) and Prettier (with prettier-plugin-tailwindcss)

## Prerequisites

- Node.js 22.22.2+ or 24.15+ (required by Vitest and jsdom)
- npm

## Getting started

```bash
npm install       # install dependencies
npm run dev       # start the dev server at http://localhost:5173
```

### Scripts

| Command                | Description                                    |
| ---------------------- | ---------------------------------------------- |
| `npm run dev`          | Start the Vite dev server                      |
| `npm test`             | Run the test suite once                        |
| `npm run test:watch`   | Run the tests in watch mode                    |
| `npm run lint`         | Lint with ESLint (fails on any warning)        |
| `npm run format`       | Format all files with Prettier                 |
| `npm run format:check` | Check formatting without writing               |
| `npm run build`        | Type-check and build for production to `dist/` |
| `npm run preview`      | Serve the production build locally             |

## Project structure

```
src/
├── components/ui/     # shadcn/ui components
├── lib/utils.ts       # shadcn's cn() helper
├── routes/            # File-based routes
│   ├── __root.tsx     # Layout
│   ├── index.tsx      # Search page (placeholder)
│   └── image.$nasaId.tsx # Details page (placeholder)
├── test/setup.ts      # Vitest setup (jest-dom matchers)
├── routeTree.gen.ts   # Generated by the TanStack Router plugin
└── main.tsx           # QueryClientProvider + RouterProvider
```
